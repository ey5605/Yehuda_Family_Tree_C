# אילן היוחסין של משפחת יהודה

אתר פרטי בעברית וב־RTL לניהול אנשים וקשרים, עם סיסמה משפחתית לצפייה וסיסמה נפרדת לעריכה. המאגר מכיל קוד בלבד; העץ מתחיל ריק. נתוני בדיקה נמצאים רק ב־`tests/fixtures` ולא מוזנים לאתר.

## היכן נשמרים הנתונים?

- **GitHub**: קוד האתר, בדיקות ותהליך הבנייה והפריסה.
- **Cloudflare Workers בחשבון שלכם**: האתר והשרת שבודק את הסיסמאות וההרשאות.
- **Cloudflare D1 בחשבון שלכם**: גרסת העץ הפעילה, הפניה לקובץ הנתונים, מטא־נתונים של תמונות והגבלת ניסיונות כניסה.
- **Cloudflare R2 פרטי בחשבון שלכם**: קובצי התמונות וגרסאות JSON של כל מודל האנשים והקשרים. כל שמירה יוצרת גרסה חדשה; עדכון מצביע הגרסה ב־D1 הוא אטומי.
- **IndexedDB בדפדפן**: טיוטות ושינויים שעדיין לא נשלחו. זהו תור מקומי לסנכרון, ולא מסד הנתונים המשותף.

GitHub Pages לבדו אינו מריץ שרת או מסד נתונים. הפריסה כאן נעשית מ־GitHub ל־Cloudflare. לא נדרש חשבון ChatGPT לבני המשפחה. אין לשלוח סיסמאות או מידע משפחתי ל־GitHub Issues.

## מה עובד

- הזנה ועריכה של אנשים, תאריכים חלקיים ומשוערים, תמונות וחיתוך בסיסי; שם בלבד הוא חובה.
- אנשים בעלי מזהים קבועים, כמה זוגיות, יחידות משפחתיות, הורות לא ידועה/ביולוגית/מאמצת, ילדים ללא תקרת מוצר ודורות ללא מגבלת עומק קבועה.
- חיבור אדם קיים, מניעת הורות עצמית ומעגלים, הסרת קשר בנפרד ממחיקת אדם, שמירת צאצאים במחיקה, סדר ילדים, ביטול וביצוע חוזר.
- תצוגה מפורטת, שמות מלמעלה למטה ושמות מימין לשמאל. חיפוש, גרירה, הגדלה, מגע, כיווץ ענפים והתאמה למסך. ציור הכרטיסים לפי האזור הנראה.
- ייבוא JSON עם בדיקה, סיכום, תצוגה מקדימה, אישור, פתרון סתירות, החלפה עם גיבוי או מיזוג לפי מזהים. אין מיזוג לפי שם ואין יצירת אנשים מסיכומי צאצאים.
- PNG של כל העץ; PDF של כל העץ על A4 יחיד; PDF מרובה עמודים ברוחב עמוד אחד, עם מזהי המשך ומפתח קשרים. הייצוא מחשב פריסה מלאה ואינו צילום מסך.
- ייצוא JSON של נתונים בלבד או גיבוי מלא הכולל את תוכן התמונות. שמירת פריטי בדיקה, אישורים ושדות נוספים.
- שמירה אוטומטית, תור עריכות במצב ניתוק, זיהוי עריכה במקביל והימנעות מדריסה שקטה.
- שתי סיסמאות והרשאות שרת: צפייה או עריכה. אין קבלת הרשאות מכותרות זהות שמגיעות מהלקוח.

## הפעלה מקומית

נדרשים Node.js 24 ו־npm. סביבת הבדיקה המקומית אינה מעלה דבר לענן.

```sh
npm ci
node scripts/setup-passwords.mjs
npm run build
node scripts/prepare-local.mjs
npx wrangler d1 migrations apply DB --local --config dist/server/wrangler.json --persist-to .wrangler/state
npm start
```

פתחו את הכתובת ש־Wrangler מציג (בדרך כלל `http://127.0.0.1:8787`). הסקריפט מבקש שתי סיסמאות שונות, לפחות 12 תווים, בלי להציג אותן על המסך. הוא שומר גיבובים ומפתח חתימה בקבצים מקומיים שה־gitignore מחריג: `.dev.vars` ו־`.secrets.generated.json`. אל תוסיפו קבצים אלה למאגר.

לעריכת קוד עם רענון אוטומטי: `npm run dev`. יש להכין קודם את מסד הנתונים המקומי. רצוי להשתמש באותו מסלול Wrangler לבדיקת שמירה מתמשכת.

```sh
npm test
npm run typecheck
npm run build
```

## הקמה חד־פעמית בחשבון Cloudflare שלכם

1. היכנסו לחשבון שלכם באמצעות `npx wrangler login`.
2. צרו מסד נתונים: `npx wrangler d1 create yehuda-family-db`. שמרו את `database_id` שהתקבל.
3. צרו אחסון פרטי: `npx wrangler r2 bucket create yehuda-family-files`. אל תפעילו קישור ציבורי לדלי. ייתכן שהפעלת R2 בחשבון דורשת הגדרת חיוב אצל הספק.
4. הריצו `node scripts/setup-passwords.mjs` במחשב שלכם ובחרו את שתי הסיסמאות. העבירו לכל בני המשפחה רק את סיסמת הצפייה; העבירו את סיסמת העריכה רק למי שמורשה לעדכן.
5. ב־GitHub, Settings → Secrets and variables → Actions, הגדירו את המשתנים והסודות הבאים. אפשר לשמור אותם גם בסביבת `production`.

| סוג | שם | ערך |
|---|---|---|
| Variable | `CLOUDFLARE_ACCOUNT_ID` | מזהה החשבון שלכם |
| Variable | `D1_DATABASE_ID` | מזהה המסד שנוצר |
| Variable | `R2_BUCKET_NAME` | `yehuda-family-files` |
| Secret | `CLOUDFLARE_API_TOKEN` | אסימון פריסה בעל הרשאות Workers Scripts, D1 ו־R2 לחשבון שלכם בלבד |
| Secret | `VIEW_PASSWORD_HASH` | הערך המקביל מתוך `.secrets.generated.json` |
| Secret | `EDIT_PASSWORD_HASH` | הערך המקביל מתוך `.secrets.generated.json` |
| Secret | `SESSION_SECRET` | הערך המקביל מתוך `.secrets.generated.json` |

6. בלשונית Actions הריצו **Deploy family tree**. התהליך מריץ בדיקות, בונה את האתר, מחיל migrations, מפרסם Worker ומגדיר את הסודות. לפני הגדרת סודות תקינה הכניסה חסומה.
7. פתחו את כתובת `workers.dev` שהפריסה מחזירה. אפשר לחבר דומיין משלכם דרך Cloudflare. התחברו בסיסמת העריכה וייבאו את קובץ המשפחה דרך הממשק, לאחר בדיקה ואישור.
8. בדקו במכשיר נוסף כניסה עם סיסמת צפייה. משתמש צפייה יכול לקרוא ולהוריד גיבוי, אך השרת דוחה שינוי עץ והעלאת תמונה.

הסיסמאות אינן שמורות בקוד או בקובצי גיבוי העץ. השרת שומר גיבובי PBKDF2 עם salt, וההתחברות יוצרת עוגיית HttpOnly חתומה ל־12 שעות, עם SameSite=Strict ו־Secure ב־HTTPS. מוגבלים ניסיונות כניסה לפי כתובת רשת. החלפת הסודות מנתקת חיבורים קיימים. מכיוון שבחרתם סיסמאות משותפות, אין זיהוי של העורך המסוים או ביטול הרשאה לאדם אחד בלי להחליף סיסמה.

## גיבוי, שחזור ועדכונים

בחרו **ייצוא והדפסה → גיבוי מלא → ייצוא נתוני העץ ל־JSON** ושמרו את הקובץ אצלכם. גיבוי מלא מכיל תמונות Base64 ואינו תלוי בכתובות האחסון הקודם. ייצוא נתונים בלבד מכיל הפניות לתמונות ואינו גיבוי מלא שלהן.

לפני החלפת עץ או מיזוג, האתר יוצר הורדת גיבוי מלא. אם הדפדפן אינו מתחיל הורדה אוטומטית, לחצו על קישור ״הקובץ מוכן״ שמופיע בחלונית. ודאו שהקובץ אכן נשמר לפני סגירת הדפדפן.

בשחזור לעץ ריק: ייבוא → בחירת JSON → בדוק קובץ → פתרון סתירות/קריאת פריטי בדיקה → אשר ייבוא. פריט לא ודאי נשאר לא ודאי גם לאחר אישור ביצוע הייבוא.

לא מוחקים או יוצרים מחדש את D1/R2 בעת עדכון האתר. שינויים בסכמה מתווספים כ־migration חדש. גרסאות JSON ותמונות ישנות נשמרות כרגע באחסון; יש להביא את נפח האחסון בחשבון ולא למחוק אובייקטים שמופיעים בגיבוי שרוצים לשחזר.

## הרחבות סכמת JSON

פורמט הבסיס נשאר `family-tree-generic` עם `persons`, `families`, `relationships`. קובץ המקור נתמך בלי להוסיף את ההרחבות.

- תאריך חדש: `{ "year": 1976, "month": 4, "precision": "month", "approximate": false }`. תאריכים מקוריים שלא נערכו נשמרים בצורתם המקורית. יום או חודש חסרים אינם מושלמים.
- תמונה: `{ "id": "…", "mimeType": "image/jpeg", "fileName": "…", "url": "/api/photos/…", "data": "data:image/jpeg;base64,…" }`. השדה `data` קיים בגיבוי מלא; בנתונים בלבד נשמרת הפניה. התמונות המקוריות בשרת נשמרות כקבצים; תמונה שנחתכה נשמרת כ־JPEG מרובע בגודל 900×900.
- סדר ידני: `person.childOrder` הוא מערך מזהי ילדים. אחרת הסדר נגזר מתאריכי הלידה הידועים.
- `metadata.exportedAt`, `metadata.statistics`, `metadata.backupMode`, `metadata.extensions` מתארים את הייצוא.
- שדות לא מוכרים נשמרים. במיזוג נשמר מקור נוסף ב־`metadata.mergedSources` והרחבות מקור ב־`importedExtensions`.
- קשרים תואמים מנורמלים לקשר יחיד. רשומות מקור נוספות נשמרות ב־`mergedRepresentations`. מזהה הקשר המפורש הראשון נשמר; קשר שהוגדר רק במערכי אנשים/משפחה מקבל מזהה פעם אחת בעת הייבוא.

## מגבלות טכניות ומצב פריסה

אין תקרת מוצר קבועה לילדים, דורות או מספר אנשים. חישוב הפריסה פועל במכשיר; עצים עצומים עדיין מוגבלים בזיכרון וביכולת המכשיר. PNG מוגבל באופן מפורש ל־40 מיליון פיקסלים ול־16,384 פיקסלים בצלע, עם הודעת הפחתת רזולוציה. תמונה להעלאה מוגבלת ל־20MB.

PDF נבנה מעמודים שרונדרו במיוחד להדפסה, באיכות כ־240dpi. עברית ותמונות נראות ללא תלות בגופנים במחשב הקורא; הטקסט בתוך ה־PDF הוא רסטר ולא טקסט ניתן לחיפוש. בתצוגה מרובת עמודים הכרטיסים נמשכים אנכית ומפתח הקשרים מציין מזהי אנשים ומספרי עמודים. בדף יחיד עץ גדול מאוד יהיה קטן מאוד, והאתר מציג את גודל הטקסט המשוער.

הבדיקות המקומיות אינן מחליפות בדיקת פריסה בחשבון Cloudflare: יש להשלים הגדרת משאבים וסודות, לפרסם ואז לוודא שמירה ורענון בשני מכשירים. אין במאגר סיסמת ברירת מחדל או עץ משפחתי אמיתי. פרטי הבדיקות נמצאים ב־`ACCEPTANCE.md`.
